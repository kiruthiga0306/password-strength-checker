# Password Strength Checker (Core Python)

## 📌 Project Description
This is a *Password Strength Checker* developed using *Core Python 3.x without any frameworks*.  
It checks whether a password contains uppercase letters, lowercase letters, numbers, and symbols, and then classifies the password as *Weak, Medium, or Strong*.

---

## 🛠 Tech Stack
- Language: Python 3.x
- Type: Console-based application
- Frameworks: None (Core Python only)

---

## ✅ Features
- Accepts password input from user
- Checks for:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- Displays password strength:
  - Weak
  - Medium
  - Strong
- Shows missing conditions (if any)
- Uses *logical checks* (no regex)

---
